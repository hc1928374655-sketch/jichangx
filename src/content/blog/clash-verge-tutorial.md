随着原生 Clash 核心项目的退役，由开源社区积极维护的 **Clash Verge Rev** 凭借其现代化的 UI 界面、内置最新的 Mihomo (Clash Meta) 强力内核，已成为当前 Windows 与 macOS 平台最推荐的日常代理客户端。

本文将手把手带你从零完成配置，全程仅需 3 分钟。

---

## 准备工作

在开始配置前，请确保你已经准备好了：
1. **电脑设备**：Windows 10/11 64位系统 或 macOS（M系列芯片 / Intel）；
2. **有效的机场订阅链接**：由你所购买的机场后台提供（通常为一条 URL 链接）。

---

## 第一步：下载并安装 Clash Verge Rev

1. 访问 GitHub 官方 Releases 页面或本站镜像页面下载对应系统架构的安装包：
   - Windows 用户建议下载：`Clash.Verge_x.x.x_x64-setup.exe`；
   - macOS 用户建议下载：`Clash.Verge_x.x.x_aarch64.dmg` (Apple Silicon 芯片)。
2. 双击安装包，按照提示点击“下一步”完成安装并启动软件。

---

## 第二步：导入机场订阅链接

1. 登录你所购买的机场服务商用户后台；
2. 找到“仪表盘”或“快速导入”区域，点击 **“复制 Clash 订阅链接”**；
3. 打开 Clash Verge Rev 客户端，点击左侧菜单栏的 **“订阅 (Profiles)”**；
4. 在顶部输入框粘贴刚才复制的订阅 URL，随后点击右侧的 **“保存 (Save)”** 或 **“下载 (Import)”** 按钮；
5. 稍等片刻，看到订阅卡片显示更新成功后，**单击选中** 该配置卡片（卡片边框变蓝即表示生效激活）。

---

## 第三步：代理模式与节点选择

1. 点击左侧菜单的 **“代理 (Proxies)”** 界面；
2. 顶部选择 **“规则 (Rule)”** 模式：
   - **规则模式**：自动识别国内外流量，访问国内网站直连不扣流量，访问外网走代理节点（推荐绝大多数用户）；
   - **全局模式**：所有网络请求全部走代理（仅在个别特定排障场景下使用）；
   - **直连模式**：所有网络均不走代理。
3. 在节点列表中，建议优先选择 **“香港 IEPL”** 或 **“日本 IEPL”** 节点，兼顾超低延迟与高速率。

---

## 第四步：启用系统代理与 TUN 模式（可选）

1. 点击左侧菜单的 **“设置 (Settings)”**；
2. 打开 **“系统代理 (System Proxy)”** 开关：此时浏览器即可正常打开 Google、YouTube 等网站；
3. **进阶极客（游戏/终端命令行必备）**：
   - 找到 **“TUN 模式 (Tun Mode)”** 开关并开启；
   - 首次开启时，Windows 会提示安装虚拟网卡驱动（Service Mode），点击授权安装即可；
   - 开启 TUN 模式后，电脑上所有未走系统代理的软件（如 Git、命令行终端、各类游戏客户端）均可自动接管加速！

## 常见问题与快速排查自检

### Q1: 导入订阅时提示 Network Error 或下载超时？
- **原因**：部分网络环境下直接访问机场订阅 API 受限。
- **解决方法**：检查机场后台是否提供了“免翻墙订阅转换短链”，或先开启手机热点尝试重新下载。

### Q2: 开启系统代理后国内微信或网页打不开？
- **原因**：规则分流发生冲突或 DNS 解析异常。
- **解决方法**：在“代理”页面确认模式是否设置为“规则模式”，勿开启“全局模式”；并在设置中开启“内置 DNS / Fake-IP”优化选项。
